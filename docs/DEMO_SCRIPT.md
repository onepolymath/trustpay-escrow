# Demo video script (under 3:00)

Record at 1080p. Tabs: <https://trustpay-sol.vercel.app> (light theme), the GitHub repo, and Solana Explorer. The demo uses the built-in **demo wallets** (no extension needed), so you can switch between buyer, vendor and arbiter from the wallet menu. The timings leave about 15 s of slack.

**Before recording**

1. Open the live site, click **Try the live demo** → **Start demo**, and let the faucet fund the demo wallets (about 10 s).
2. As the vendor, create your storefront (**Create storefront**, handle e.g. `@ummie.styles`) so registration doesn't eat recording time.
3. Create one throwaway order and complete it, so the reputation card isn't empty.
4. Use the **2 minutes (demo)** windows so auto-release could fire on camera if needed.
